Verdict

粗粒度房級有初步訊號，精度／連通／房型不足

約六成 GT rooms 能在 IoU>0.5 下配對，成功配對者通常有合理範圍；這是可供後續研究驗證的初步訊號，不代表目前已足以直接掛接下游 attributes。精確角點、房間連通圖與房型分類仍不足。

  • ~0.60 / 0.78粗粒度房級：Room F1 / matched-房 conditional IoU — 有初步訊號；仍需 downstream validation
  • ✗0.20邊界精度：Corner@10cm — 門寬/貼牆開向這類要精確牆線的屬性不可靠
  • ✗0.13連通拓撲：access-graph edge — 不足以直接當導航圖
  • ✗0.14房型：Room+type — CLIP 房型近乎失效

誠實的方法學邊界
GT geometry 已改為官方 floor polygons。 Current GT 直接讀 MP3D `.house` 的 R→S(F)→ordered V，不再經 rasterization／morphology／RDP。房級 IoU 0.78 仍是「僅成功 matched 房」的 conditional mean（非全房平均）。
Tier C 打折。 MP3D 這 16 棟 #portals=0，連通 GT 是推導的（point-in-polygon 探針，移植自 Structured3D）。該規則在真掃描 GT 上內門準確率 78.9%（合成 S3D 為 98.2%）、外門佔比 25%≈S3D 23%。故 Tier C 是「預測 vs 79% 可信 GT」，讀數要打折。
Evaluator／GT A/B 已完成。 Legacy v2＋raster GT 的 Room F1 0.613；strict v3 對相同 raster GT 為 0.597；strict v3＋官方 polygons 的共同 324-room subset 為 0.603；current explicit 325-room set 為 0.602。GT overlap 從 1.44% 降至 0.13%。舊 baseline 未被覆寫。

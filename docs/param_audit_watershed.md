## ROOM_CORE_MIN 過擬合實測（`src/eval` 一次性腳本）

16 棟 268 GT 房的 inradius（距牆最大距離）：
- **inradius < 0.5m（會漏種子→併房）：11 房 = 4%**
- 分位：p10=0.63 / p25=0.80 / 中位=1.20
- 2t7W 中位 1.54（偏大房）但門檻 0.5 遠低於全體 p10 → **非對 2t7W 大房過擬合**
- 受影響棟：YFuZ(5)、1LXt(3)、Jmb/e9zR/p5w 各 1 → 這些棟小房略欠分割，可局部降門檻
